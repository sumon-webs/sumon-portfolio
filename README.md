# 🚀 Run Locally

## 1. Clone the repository

```bash
git clone https://sumon-portfolio-mu.vercel.app/
```

## 2. Navigate to the project directory

```bash
cd project-folder
```

## 3. Install dependencies

```bash
npm install
```

## 4. Configure Environment Variables

Create a `.env.local` file and add your environment variables.

```env
EMAIL_SERVICE_ID=
EMAIL_TEMPLATE_ID=
EMAIL_PUBLIC_KEY=
```

> If you're using a different email service (such as Resend, Nodemailer, or FormSubmit), replace these variables with the ones required for your setup.

## 5. Run the development server

```bash
npm run dev
```

Open **http://localhost:3000** in your browser to view the project.
